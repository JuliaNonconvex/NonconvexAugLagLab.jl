Options

AugLagOptions controls the outer augmented Lagrangian loop:

OptionDefaultMeaning
sub_optionsnothingoptions for the sub-solver (or the built-in QuasiNewtonAlg)
relaxedRelaxConstraintSelection()which constraint kinds to relax (see below)
penalty:quadratic:quadratic (classical ALM), :pbm (penalty-barrier-multiplier for inequalities) or :mixed (PBM for inequalities, quadratic for equalities)
ρ_init10.0initial penalty weight
ρ_max1e10penalty cap (infeasibility detection)
ρ_incr10.0penalty increase factor on insufficient progress
ρ_decr10.0penalty decrease factor on successful multiplier steps (two-way adaptation)
max_iter1000maximum outer iterations
ctol1e-6feasibility tolerance
η₀0.5initial feasibility target of the subproblems
ω₀1.0initial optimality target of the subproblems
weightsnothingper-constraint-group penalty weights (default: all ones)
lsq_multiplierstrueinitialize equality multipliers from the least-squares stationarity residual (matrix-free CGLS on Jv/Jᵀv products only)
scalingtruenormalize relaxed constraints by their gradient magnitudes and the objective by its initial magnitude
memory50L-BFGS memory of the built-in sub-solver (one warm-started history across outer iterations)
elasticfalseelastic ALM: relax equalities through slack variables
elastic_μ1e3slack penalty coefficient of the elastic mode
warm_continuefalsereuse the previous run's iterate, rescaled multipliers, weights and curvature when optimize! is called again on the same workspace
keep_allfalsekeep the trajectory of outer iterates in the result

Penalty modes

The three penalty modes differ in how the relaxed inequality constraints enter the augmented Lagrangian objective; relaxed equalities always use the quadratic term.

# Classical quadratic ALM: λᵀmax(g,0) + (ρ/2)‖max(g,0)‖²
options = AugLagOptions(penalty = :quadratic)

# PBM (Ben-Tal & Zibulevsky): shifted logarithmic barrier on the feasible
# side, quadratic fallback on the infeasible side
options = AugLagOptions(penalty = :pbm)

# Mixed: PBM for inequalities, quadratic for equalities
options = AugLagOptions(penalty = :mixed)

Relaxation selection

RelaxConstraintSelection selects which constraints are relaxed into the augmented Lagrangian. Each entry is true (relax all of that kind), false (keep all hard) or a vector of constraint indices (relax those only). Box constraints are always handled by the sub-solver.

# relax all equalities and inequalities
RelaxConstraintSelection()

# keep equalities hard, relax everything else
RelaxConstraintSelection(eq = false)

# relax only the first inequality constraint
RelaxConstraintSelection(eq = false, ineq = [1], sd = false)

When AugLagAlg() is used without a sub-solver, every constraint must be relaxed: the built-in QuasiNewtonAlg only handles smooth box-constrained subproblems.
