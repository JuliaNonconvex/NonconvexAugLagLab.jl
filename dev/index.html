Augmented Lagrangian in pure Julia

Description

NonconvexAugLagLab.jl provides AugLagAlg, an augmented Lagrangian meta-algorithm for equality-, inequality- and (with NonconvexSemidefinite loaded) semidefinite-constrained problems. Constraints selected for relaxation (RelaxConstraintSelection) are folded into an augmented Lagrangian objective; the remaining constraints stay hard for the sub-solver. The outer loop follows the practical scheme of Birgin & Martínez: feasibility-driven adaptive penalty, tolerance sequences, multiplier safeguards and infeasibility detection. Three penalty modes are available (penalty = :quadratic | :pbm | :mixed, see Options below). The built-in sub-solver is a smooth box-constrained quasi-Newton optimizer, QuasiNewtonAlg, with pluggable Hessian approximations.

The theory is reviewed in Theory: the classical ALM, the practical Birgin–Martínez loop, the penalty-barrier-multiplier (PBM) method, the projected ALM for semidefinite constraints, and the quasi-Newton sub-solver machinery.

Quick start

using NonconvexAugLagLab

# min x₁² + x₂² s.t. x₁ + x₂ = 1 → (0.5, 0.5)
m = Model(x -> sum(x .^ 2))
addvar!(m, [-5.0, -5.0], [5.0, 5.0])
add_eq_constraint!(m, x -> x[1] + x[2] - 1)
r = optimize(m, AugLagAlg(), [0.0, 0.0])
r.minimizer   # ≈ [0.5, 0.5]
r.minimum     # ≈ 0.5

Semidefinite constraints

With NonconvexSemidefinite loaded, AugLagAlg additionally supports semidefinite constraints through a projected augmented Lagrangian: the constraint violation is computed through the PSD projection (project_psd) and the multiplier update uses the projected multiplier update of the PSD cone. A problem with a matrix-valued constraint is modeled with add_sd_constraint!:

using NonconvexAugLagLab, NonconvexSemidefinite, LinearAlgebra

# min ‖X - A‖²_F s.t. X ⪰ 0 over the lower-triangular entries of X
A = [2.0 0.5; 0.5 1.0]
m = Model((x_l, x_d) -> sum(abs2, decompress_symmetric(x_l, x_d) .- A))
addvar!(m, fill(-5.0, 1), fill(5.0, 1), fill(0.0, 2)) # 1 lower + 2 diagonal entries
add_sd_constraint!(m, (x_l, x_d) -> decompress_symmetric(x_l, x_d))
r = optimize(m, AugLagAlg(), [fill(1.0, 1), fill(1.0, 2)])
X = decompress_symmetric(r.minimizer...)
X  # ≈ the PSD projection of A

The semidefinite relaxation is controlled like the other constraints through RelaxConstraintSelection: sd = false keeps the semidefinite constraints hard for the sub-solver, sd = true (default when relaxing) folds them into the augmented Lagrangian. The multiplier update for the :pbm and :mixed penalty modes also barrier-ifies inequality constraints; the semidefinite terms are always handled by the projected update. See Theory for the derivation.

AugLagAlg() uses the built-in QuasiNewtonAlg, which requires every constraint to be relaxed. To keep some constraints hard, pass a sub-solver that supports them:

using NonconvexAugLagLab, NonconvexIpopt

alg = AugLagAlg(IpoptAlg())                       # Ipopt solves the subproblems
options = AugLagOptions(
    sub_options = IpoptOptions(max_iter = 100),   # sub-solver options
    relaxed = RelaxConstraintSelection(eq = false), # keep equalities hard
)
r = optimize(m, alg, [0.0, 0.0], options = options)

Options

AugLagOptions controls the outer augmented Lagrangian loop:

Penalty modes

The three penalty modes differ in how the relaxed inequality constraints enter the augmented Lagrangian objective; relaxed equalities always use the quadratic term.

# Classical quadratic ALM: λᵀmax(g,0) + (ρ/2)‖max(g,0)‖²
options = AugLagOptions(penalty = :quadratic)

# PBM (Ben-Tal & Zibulevsky): shifted logarithmic barrier on the feasible
# side, quadratic fallback on the infeasible side
options = AugLagOptions(penalty = :pbm)

# Mixed: PBM for inequalities, quadratic for equalities
options = AugLagOptions(penalty = :mixed)

Relaxation selection

RelaxConstraintSelection selects which constraints are relaxed into the augmented Lagrangian. Each entry is true (relax all of that kind), false (keep all hard) or a vector of constraint indices (relax those only). Box constraints are always handled by the sub-solver.

# relax all equalities and inequalities
RelaxConstraintSelection()

# keep equalities hard, relax everything else
RelaxConstraintSelection(eq = false)

# relax only the first inequality constraint
RelaxConstraintSelection(eq = false, ineq = [1], sd = false)

When AugLagAlg() is used without a sub-solver, every constraint must be relaxed: the built-in QuasiNewtonAlg only handles smooth box-constrained subproblems.

Result

optimize returns an AugLagResult with the usual GenericResult-style fields minimizer and minimum. With AugLagOptions(keep_all = true) the full outer-loop trajectory — one (x, objective, violation) tuple per outer iteration — is available as r.trajectory.

options = AugLagOptions(keep_all = true)
r = optimize(m, AugLagAlg(), [0.0, 0.0], options = options)
r.trajectory  # vector of (x, f(x), ‖v(x)‖∞) per outer iteration

Quasi-Newton sub-solver

QuasiNewtonAlg is a smooth box-constrained quasi-Newton optimizer usable standalone or as the built-in sub-solver of AugLagAlg(). The Hessian model is selected by passing any AbstractHessianApprox:

# L-BFGS (default): memory-limited two-loop recursion
alg = QuasiNewtonAlg()
alg = QuasiNewtonAlg(LBFGSApprox(20))

# Dense BFGS: inverse Hessian (default) or direct Hessian + factorization
alg = QuasiNewtonAlg(DenseBFGSApprox())
alg = QuasiNewtonAlg(DenseBFGSApprox(form = :hessian))

# Structured BFGS: secants restricted to a user-defined sparsity pattern
using SparseArrays
alg = QuasiNewtonAlg(StructuredBFGSApprox(spdiagm(ones(2))))

# Newton trust region: exact AD Hessian with the Steihaug–Toint method
alg = QuasiNewtonAlg(NewtonTRApprox(); linesearch = :trustregion)

The linesearch keyword is :backtracking (Armijo, default), :wolfe (strong Wolfe) or :trustregion (Steihaug–Toint with a projected step, needed for NewtonTRApprox); max_iter, tol, damping (Powell damping) and Δ0 (initial trust-region radius) tune the driver.

Preconditioners

LBFGSApprox(memory; H0 = ...) accepts a base operator used at the bottom of the two-loop recursion:

alg = QuasiNewtonAlg(LBFGSApprox(10))                          # identity
alg = QuasiNewtonAlg(LBFGSApprox(10; H0 = DiagonalPreconditioner(d)))

IdentityPreconditioner applies the identity scaling; DiagonalPreconditioner(d) multiplies by d (with entries all positive) and divides when solving. See Theory for how the preconditioner enters the recursion.

Custom Hessian approximations

Any subtype of AbstractHessianApprox plugs into QuasiNewtonAlg. Implement the interface

struct MyApprox <: AbstractHessianApprox; ...; end
NonconvexAugLagLab.init!(H::MyApprox, n, x0)   # allocate/initialize
NonconvexAugLagLab.apply!(Hv, H::MyApprox, v)  # matrix-vector product
NonconvexAugLagLab.update!(H::MyApprox, s, y)  # accumulate the secant pair
NonconvexAugLagLab.solve!(d, H::MyApprox, g)   # solve the Newton system
Base.reset!(H::MyApprox)                       # drop accumulated curvature

Default implementations are provided for dense matrices, sparse matrices (pattern-based) and diagonal scaling, so custom containers only need the methods relevant to their structure. The full extension API is documented in the docstrings of AbstractHessianApprox.
